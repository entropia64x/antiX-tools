# antiX Linux utilities

A collection of small shell scripts and configuration helpers for antiX Linux and IceWM.

These scripts were created to solve practical problems encountered while configuring and using antiX on older hardware. Some were developed with the assistance of ChatGPT; I tested, adapted, and used them in my own system.

They are shared primarily as practical examples and possible solutions for other antiX users. They may require modification depending on the user's hardware, desktop environment, or configuration.

## Contents

* system and desktop utilities
* IceWM helpers
* terminal and transparency configuration
* application launchers
* miscellaneous maintenance scripts

## Notes

These scripts are provided as-is. Review them before running them, especially scripts that modify configuration files or system settings.
